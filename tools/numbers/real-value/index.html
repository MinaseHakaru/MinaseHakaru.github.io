数字を読み解く

実質値

物価が変わると、同じ金額の意味も変わります。名目の金額を、物価をそろえた価値に直します。

いまの金額が、物価が変わったあとの世界でどれだけの買い物に相当するかを測ります。

物価倍率
—
実質値
—
購買力の増減

文章にすると

使い方

金額と、物価がどれだけ上がるかを入れてください。年率で測るは、年平均の上昇率が何年続くかで測ります。期間全体で測るは、期間を通して何％上がったかを直接入れます。入口が二つあるだけで、測っているものは同じ「物価の比」です。

物価上昇率にマイナスを入れれば、物価が下がる場合も測れます。

計算の考え方

年率で測る 物価倍率 = (1 + 年平均の物価上昇率) ^ 年数 期間全体で測る 物価倍率 = 1 + 期間全体の物価上昇率 実質値 = 名目の金額 ÷ 物価倍率

物価が上がると、同じ金額で買えるものは減ります。掛けるのではなく割るのは、そのためです。物価倍率が1より小さいとき（物価が下がったとき）は、割った結果は元の金額より大きくなります。

例

100万円、年2％、10年で測ります。物価倍率は 1.02 の10乗で約1.219倍。100万円をこれで割ると約82万円です。

つまり、いまの100万円は、10年後の物価のもとでは、いまの約82万円分の買い物にしか相当しません。金額は100万円のまま変わらないのに、買えるものが18％ぶん減っている。これが名目と実質のずれです。

注意

  • 消費者物価指数は、平均的な家計が買う財・サービスの価格変動を測る指標です。個々の家計の生活費の上昇率そのものではありません。
  • 実際の物価の動きを使う場合は、どの系列か（総合、生鮮食品を除く総合など）と、期間の取り方（年平均、年度平均、前年同月比）を確認してください。同じ「物価上昇率」でも別の数字になります。
  • 長い期間を一定の年率で計算した結果は、その率がずっと続いたと仮定した場合の試算です。実際の物価は毎年動きます。

実際の物価の動きは、総務省統計局の消費者物価指数で確認できます。この道具は物価のデータを持たず、入力された率から関係を測るだけです。

入力内容はすべてブラウザ内で処理され、外部には送信されません。
